# Agent guidance

- Read the root `CLAUDE.md` and the app's `CLAUDE.md` before making changes.
- Use pnpm from the repository root. Keep app dependencies and configuration in their workspace.
- Preserve unrelated work and both applications' behavior.
- Verify the affected app and report any checks that need external services.
- Commit verified chunks of implementation. Keep unrelated changes out of each commit.
- Update the relevant current guide when behavior or setup changes. Preserve dated historical feature records and label superseded decisions.
- Follow the user's scope for commits, previews, database changes, and deployment.
